# RTOS Lab Repository

## Overview
This repository contains a collection of laboratory experiments performed as part of a Real-Time Operating Systems (RTOS) course. The experiments are implemented using the STM32 Nucleo-F446RE microcontroller and demonstrate key concepts of embedded systems and real-time processing.

The repository is structured in a clear and organized manner, with each experiment documented through theory, procedure, code, and results.

---

## Objectives
The primary objectives of this repository are:
- To understand embedded system fundamentals  
- To implement input and output interfacing using GPIO  
- To explore sensor integration and signal processing  
- To develop PWM-based control systems  
- To understand task scheduling using RTOS  

---

## Experiments Included

### Experiment 1: GPIO LED Control
- Configuration of GPIO as output  
- Control of onboard LED  

### Experiment 2: Push Button Controlled LED
- Digital input handling  
- LED toggling using button press  

### Experiment 3: Ultrasonic Sensor Interfacing
- Distance measurement using HC-SR04  
- Time-of-flight calculation  

### Experiment 4: PWM Signal Generation
- PWM generation using timers  
- LED brightness control  

### Experiment 5: Super Loop Based System
- Cooperative multitasking using a single loop  
- Time-based task execution  

### Experiment 6: FreeRTOS Task Implementation
- Task creation using FreeRTOS  
- Scheduler-based execution
